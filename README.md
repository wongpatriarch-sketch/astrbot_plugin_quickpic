# 快捷图库（astrbot_plugin_quickpic）

群友发送指令，机器人直接回一张本地同名图片，不带任何文字。

## 图片放哪里

```
AstrBot/data/plugin_data/astrbot_plugin_quickpic/images/
```

插件首次加载时会自动创建这个目录，并在日志里打印它的绝对路径。

> 图片**不要**放在 `data/plugins/astrbot_plugin_quickpic/` 里——那是插件代码目录，更新或重装插件时会被覆盖。

## 怎么用

图片文件名就是指令名，支持的扩展名（不区分大小写）：
`.jpg` `.jpeg` `.png` `.gif` `.webp` `.bmp`

| 文件 | 群友发送 | 结果 |
| --- | --- | --- |
| `课表.png` | `@机器人 /课表` 或 `@机器人 课表` | 回复这张图片 |
| `菜单.jpg` | `@机器人 /菜单` | 回复这张图片 |
| （无同名文件） | `@机器人 今天天气` | 静默放行，交给正常对话流程 |

同一个名字存在多个后缀（如 `课表.png` 和 `课表.jpg`）时，按上面列出的扩展名顺序取第一个。

## 增删图片

直接往 `images/` 目录里丢文件、覆盖文件或删文件即可，**不需要重启 AstrBot，也不需要重载插件**。插件每收到一条消息都会实时扫描一次目录。

## 说明

- 所有群友和用户都能触发，没有权限限制。
- 命中图片后插件会终止该条消息的后续传播，不会再触发大模型回复。
- 关键词为空、或包含 `/`、`\`、`..` 等路径穿越字符时，插件直接忽略该条消息。
- 文件名和扩展名都不区分大小写：`Menu.png` 可以用 `/menu`、`/MENU`、`/Menu` 触发。
- 图片优先级高于 AstrBot 内置指令和其他插件的同名指令。所以别把图片命名成 `help`、`plugin` 这类内置指令名，否则 `/help` 会变成发图。

## 可能遇到的问题

- **`.bmp` 发不出去**：QQ 官方富媒体接口对图片格式有限制，`.bmp` 有可能上传失败（日志里会有报错）。遇到就转成 `.png` 或 `.jpg`。
- **图片没反应**：先看 AstrBot 日志里那行 `[快捷图库] 请把图片放到该目录：...`，确认图片确实在那个目录下，且文件名（不含扩展名）和你发的指令一字不差。
